# MILESTONE 2 — Cockroach 验证记录

日期：2026-09-15。实现范围为规格书阶段 5，默认 **1 Fly + 20 Cockroaches**。

## 新增实现

- `Creatures/Cockroach/*`：Hidden / Emerge / Crawl / Panic / Flee，45–95 px/s 爬行、220–420 px/s 逃跑、约 160px 恐惧范围、±20° 逃跑偏角。
- `DesktopPopulation`：保留苍蝇，从主屏四周创建 20 只蟑螂，随机延迟后陆续出现。
- `CockroachSteering`：近邻避让与边缘方向计算；完全重叠时有非零逃离方向，不产生 NaN。
- `CreatureKind` 与只读邻居上下文：生物仍不依赖 WPF / Win32。渲染器按类型选择两帧缓存素材，不新增每只虫控件或定时器。
- Overlay 的重绘条件改为全部生物的可见状态，避免苍蝇飞走后蟑螂停止显示。
- Debug HUD 显示蟑螂数量和全部可见数量；托盘更新为“苍蝇与蟑螂”。

## 原生窗口与 App 生命周期

Debug 和发布版均运行 `scripts/Test-Overlay.ps1`：窗口样式 `0x80800A8`，主屏 `0,0,1920,1080`，DPI 96；启动未改变前台窗口，命中测试穿透。

诊断工具的 `--live` 模式启动真实 App 类及其生产 Overlay，不注入鼠标输入。它在约 8 秒时检查可见群体，然后调用生产暂停方法；约 13 秒确认窗口隐藏且模拟时间未变化，恢复；约 20 秒确认窗口可见、更新继续、仍有生物，然后安全退出。

该检查通过。它验证 App 生命周期与生产暂停/恢复路径，不等价于用鼠标点击托盘菜单。实际渲染面的透明截图见 `artifacts/live-probe/live-overlay.png`，原始时间序列见同目录 `samples.json`。检查时 20 只蟑螂均出现，苍蝇因鼠标静止处于屏外。

## 性能记录与限制

独立 Release 进程运行 60 秒，全程存活：

- CPU 时间增加约 22.06 秒，平均约为一个核心的 36.8%；本机 12 个逻辑处理器，按总容量折算约 3.1%，不是活跃甩鼠标压力测试。
- 私有内存约 84.4–99.5MiB，存在回落；工作集约 149.1–163.8MiB。
- 句柄从 399 降至 393。
- 原始数据：`artifacts/runtime-milestone2.json`。

真实 App 诊断中，20 只蟑螂出现后的主循环更新频率约 32–57Hz，逻辑更新时间约 0.01ms。暂停后的约 4 秒窗口内 CPU 时间仅增长约 0.05 秒，模拟时间未变化。恢复后更新继续。诊断过程还生成了全屏离屏图，因此它的内存数值不能直接替代独立进程采样。

**尚未达到稳定 60 FPS。** 当前证据表明模拟逻辑时间很短，但尚未进一步区分 WPF 绘制、桌面合成和宿主负载的影响；没有据此提前更换渲染引擎。长期内存稳定、真实鼠标操作体验、不同 GPU 与系统 DPI 切换仍需后续验证。
