# 动作与外观验证 · v0.3.0

## 实现

- 苍蝇接近固定落点时逐渐减速，精确到达后停留 3 秒；先站稳，再分段搓足，离开前短暂停顿。
- 蚂蚁与毛毛虫使用有上限的转向速度，急转时放慢移动；蟑螂朝向平滑变化。
- 爬行步态按实际移动距离推进，停止时保持姿势；蟑螂从两帧改为八帧。
- 写实与可爱风格覆盖苍蝇、蟑螂、蚂蚁、毛毛虫，使用缓存并冻结的 WPF 图形。
- 桌面风格切换立即保存，不重建昆虫；新显示器沿用所选风格。屏保单独保存风格，完整屏保及系统小窗口预览均应用。
- 旧配置没有 Style 字段时保持写实风格。
