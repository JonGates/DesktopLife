# Multi-display implementation plan

**Goal:** 当前扩展桌面每个屏幕默认 1 Fly + 20 Cockroaches，总数量随屏幕数变化。
**User override:** 用户要求现在支持多屏；规格书中把多屏放到未来阶段的排期不再适用。

## Design

- Win32 EnumDisplayMonitors / MONITORINFOEX 获取独立逻辑显示器、设备名、物理矩形和主屏标志。复制显示模式按 Windows 提供的逻辑桌面计数，不在相同桌面上叠加重复群体。
- 每屏一个 Overlay 和 SimulationWorld，坐标仍是全局物理像素；每个 WPF 窗口使用自己的 DPI 变换。负坐标、上下排列和分辨率不同都按实际矩形处理。
- App 中一个 DesktopHost 统一订阅渲染事件、每帧读取一次鼠标、更新全部世界。暂停、恢复和退出对所有屏幕一起生效。
- 鼠标只触发所在屏幕的生物；输入命中使用半开区间，避免屏幕接缝同时触发两组。
- 显示器连接、断开或布局变化后同步世界和窗口：不受影响的屏幕保留生物状态；新屏或位置/尺寸改变的屏幕重新生成一组；拔掉的屏幕释放窗口和世界。重复事件不重复增加数量。暂停期间接入屏幕仍保持暂停。
- 托盘显示屏幕数及总 Fly / Cockroach 数量。
