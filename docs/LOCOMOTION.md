# 跳跃与飞行 · 开发预览版

## 使用方式

在昆虫配置中把蟋蟀、蚱蜢或瓢虫数量设为大于 0，保存即可。动作自动发生，无需新增快捷键。写实与可爱外观、桌面与屏保共用运动逻辑。

- **蟋蟀、蚱蜢**：行走一段时间后偶尔跳跃。鼠标进入附近约 80 像素范围可以提前触发跳跃；落地后至少间隔约 2.5 秒才允许再次受惊跳跃。普通自主跳跃间隔随机约 3–7 秒。
- **跳跃阶段**：约 0.15–0.22 秒准备，0.45–0.65 秒腾空，0.15 秒落地缓冲。后腿先蹬出，再收拢，接近落点时伸出；空中不继续播放行走步态。
- **瓢虫**：约 5–12 秒地面活动后起飞，飞行约 2–4 秒再降落。起飞阶段先展翅再离地，降落阶段先触地再收翅。鞘翅与拍动的膜翅分别绘制。
- **暂停**：模拟时间与拍翅时间同时停止，继续后从当前阶段接着运动。
- **多屏**：相接边缘可以通过。每一步都受实际屏幕矩形约束，不会穿过屏幕布局中的空隙。屏幕移除导致个体重新定位时，安全回到地面状态。
- **尺寸**：高度与附肢按个体百分比缩放，既有数量与尺寸配置保持兼容。

这里的高度是俯视画面的视觉高度：身体在影子上方偏移，配合腿部姿态体现腾空，不是完整三维物理。蚱蜢当前只新增跳跃，尚未实现飞行；其他昆虫保留原有行为。

## 实现与验证

`LocomotionState`、`MotionProgress`、`Elevation`、`WingSpread` 将行为与绘制分开。`CrawlingInsect` 驱动分阶段运动，`WpfCreatureRenderer` 使用缓存姿态与模拟时间绘制。瓢虫展翅程度和拍翅帧相互独立，暂停不会继续拍翅。

```powershell
dotnet test DesktopLife.sln -c Release
dotnet run --project tools/DesktopLife.Diagnostics -c Release -- --locomotion artifacts/locomotion
dotnet run --project tools/DesktopLife.Diagnostics -c Release -- --screensaver-check artifacts/screensaver-check
```

行为测试覆盖阶段顺序、冷却、翅膀与离地顺序、落地速度、屏幕连接与空隙、无效时间步、尺寸变化和屏幕热插拔。渲染诊断检查两种外观在 100% / 125% / 150% DPI 下的阶段区别、透明背景、拍翅与暂停，并输出带明确标注的动作示意帧；这些示意帧不是桌面实录。
