# 苍蝇绕飞、点击停落与写实素材验证

日期：2026-09-15。

## 行为

- 鼠标静止时持续绕飞；左键按下记录原始全局物理坐标，当前苍蝇群体收到同一落点。
- Landing 保持固定目标，最多 420 px/s 飞行；到达才开始 Landed 3 秒。停落期间速度为 0，移动鼠标不改变位置。
- 新点击重新指定落点；同一点再次点击重置三秒。事件序号去重，旧事件不会反复延长停留。
- 三秒使用真实更新间隔，运动仍限制为每步 50ms；暂停期间不更新计时并丢弃点击。
- 热插拔移除落点时取消原目标。无效/空隙中的点击不触发降落。
- 写实苍蝇采用透明 PNG 图集，左停落、右飞行，程序集嵌入，启动时缓存；渲染通过 IsResting 选择姿态。

## 输入实现

GlobalMouseClickSource 在 WPF 消息循环线程注册 WH_MOUSE_LL，只处理 WM_LBUTTONDOWN。回调仅识别窗口和写入一个有界的最新点击信箱，始终 CallNextHookEx，不拦截输入。设置窗口/本进程非透明菜单窗口的点击被忽略；透明 Overlay 不作为控件排除。退出释放钩子。

技术参考：[Microsoft LowLevelMouseProc](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelmouseproc)、[MSLLHOOKSTRUCT](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-msllhookstruct)。系统托盘图标由 Explorer 承载，单击图标也可能按普通桌面左键指定落点；设置窗口本身不触发。

## 验证边界

主循环诊断将确定性事件写入生产信箱，不向用户桌面注入点击。真实原生钩子的注册和释放已验证；不同应用中的物理点击、系统托盘操作及长时间钩子稳定性仍需实际使用验收。实际双屏均为 100% 缩放；125%/150% 为离屏渲染验证。未宣称达到稳定 60 FPS。

生成图像是写实素材，不是实拍照片。飞行与收翅姿态各一张；飞行姿态包含翅膀运动模糊，不是逐帧摄影动画。
