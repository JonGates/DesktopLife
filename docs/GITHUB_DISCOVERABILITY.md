## 项目定位

DesktopLife：Windows 桌面宠物与交互式桌面昆虫。主要功能是鼠标跟随、多屏移动、可调昆虫数量和便携运行。

英文常用表述：Windows desktop pets、interactive insects、desktop companion、multi-monitor、mouse-following fly、portable Windows app。将这些词自然用于介绍和功能说明，不添加与项目无关的热门标签。

## 每次发布时检查

1. 中英文 README 的版本、下载链接、功能和实际发布包保持一致。
2. Release 标题包含项目名、版本和 Windows Desktop Pets；说明包含中英文下载步骤，保留预览版标识和校验信息。
3. 保留真实运行 GIF；新增 GIF 时兼顾清晰度、体积及页面首屏加载。
4. Topics 只标记实际功能或技术，不添加未实现的平台、功能和无关项目名。
5. 在 GitHub 搜索中检查 `DesktopLife`、`desktop pets in:name,description,readme`、`topic:desktop-pet language:C#` 等查询。搜索索引更新可能滞后；不以刚修改后的位置判断效果。

GitHub 支持按仓库简介、Topics 和 README 内容搜索；Topics 也提供主题浏览入口。以上改动改善可检索信息和访问者理解，不保证排名、收录时间或 Star 增长。
