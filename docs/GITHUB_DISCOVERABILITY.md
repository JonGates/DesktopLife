# GitHub 项目展示维护

## 项目定位

DesktopLife：Windows 10/11 昆虫屏保与桌面宠物。屏保支持深浅色背景和自动游走；桌面模式支持鼠标跟随。两种模式均支持多屏、可调昆虫数量和自带运行环境的便携包。

英文常用表述：Windows insect screensaver、screen saver、Windows desktop pets、interactive insects、desktop companion、multi-monitor、mouse-following fly、portable Windows app。将这些词自然用于介绍和功能说明，不添加与项目无关的热门标签。

## 每次发布时检查

1. 中英文 README 的版本、下载链接、功能和实际发布包保持一致。
2. 一个项目版本对应一个 Release，标题同时说明 Desktop App 与 Screensaver；从同一标签分别构建两个子程序，使用相同版本号，上传两个 ZIP 及一个 `SHA256SUMS.txt`（包含两个 ZIP 各自的校验值）。发布页提供两种程序的下载对照，旧 Release 仅作为历史版本，保留预览版标识和校验信息。
3. 保留真实运行 GIF；新增 GIF 时兼顾清晰度、体积及页面首屏加载。
4. Topics 只标记实际功能或技术，不添加未实现的平台、功能和无关项目名。
5. 在 GitHub 搜索中检查 `DesktopLife`、`windows screensaver in:description,readme`、`desktop pets in:name,description,readme`、`topic:screensaver language:C#` 等查询。搜索索引更新可能滞后；不以刚修改后的位置判断效果。

GitHub 支持按仓库简介、Topics 和 README 内容搜索；Topics 也提供主题浏览入口。以上改动改善可检索信息和访问者理解，不保证排名、收录时间或 Star 增长。
