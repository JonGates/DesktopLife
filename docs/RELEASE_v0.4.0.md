# DesktopLife v0.4.0 — 12 Insect Types / 12 种昆虫

同一版本包含桌面应用与 Windows 屏保；两个 ZIP 均自带运行环境。

- 新增瓢虫、步甲、蠼螋、衣鱼、蟋蟀、蚱蜢、螳螂、竹节虫，共 12 种。
- 新增昆虫采用独立写实身体纹理与附肢结构，并具有不同的爬行速度、转向和停步节奏。
- 桌面和屏保均可独立设置数量、最小／最大尺寸。新种类默认关闭，尺寸默认 80%–120%，保留旧配置。
- 体型采用代表性的相对比例，不是实际毫米校准；新增物种当前不模拟跳跃或起飞。
- 新增 8 种始终采用写实外观；可爱风格继续适用于原有 4 种。

## 下载 / Downloads

- `DesktopLife-Portable-win-x64-v0.4.0.zip`：桌面版，解压后运行 `Start-DesktopLife.cmd`，在“更多昆虫”设置数量。
- `DesktopLife-ScreenSaver-win-x64-v0.4.0.zip`：屏保版，解压后运行 `Configure-ScreenSaver.cmd` 配置，`Install-ScreenSaver.cmd` 安装。
- `SHA256SUMS.txt`：两个 ZIP 共用的校验清单。

Windows 10/11 x64 预览版。更新前从托盘退出旧桌面程序，再运行新版本。

Adds eight realistic insect types to both desktop and screen saver modes. Each supports population and size controls; new species default to zero to preserve your existing setup. Relative proportions and grounded walking are modeled; jumping and takeoff are not yet simulated for the additions.
