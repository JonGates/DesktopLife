# 共享桌面与数量控制验证记录

日期：2026-09-15。替代旧版“每屏固定数量”规则。

## 交付行为

- 全桌面共用一个 SimulationWorld、MouseTracker、CreatureManager；默认 1 Fly / 20 Cockroaches。
- 数量窗口支持苍蝇 0–20、蟑螂 0–500；保存并立即应用，增减差额，保留其余个体。0 可关闭物种。
- 配置位于 %AppData%/DesktopLife/settings.json，临时文件写完后替换；无效文件回退默认并提示，写入失败不改变活跃群体。
- 托盘菜单、双击图标、启动脚本均能打开设置。再次使用 --settings 启动时，通过本地命名事件通知现有实例，再退出第二实例。
- 每个窗口只是共享世界的一个视口，使用自己的物理坐标与 DPI；设置窗口允许正常操作，桌面覆盖层保持穿透。
- DesktopLayout 计算显示器矩形并集的外露边界。内部接缝可连续通行，错位屏幕只允许通过实际相接段；空隙和角点接触不构成蟑螂通道。
- 蟑螂普通爬行、逃跑和重新出现均处理真实边界。苍蝇跟随全桌面鼠标，离开时在第一条外露边界外隐藏，不在另一屏内部消失。
- 热插拔保持个体 ID 和总数；失去屏幕的个体投影回最近可用位置。零屏停止更新并保留群体，重连恢复。

## 限制

- 本机实际硬件为两块 1920×1080、100% 缩放屏幕。混合 DPI 的证据为 WPF 离屏渲染，负坐标/插拔为注入拓扑驱动真实窗口；没有改变操作系统布局或做物理拔插。
- 真实鼠标跨屏观感和长期运行仍需用户体验验证；自动检查覆盖状态机的连续移动与实际渲染拼合。
- 本次短期运行记录主循环约 19–26 Hz；期间存在构建负载，不能作为严格性能对比。尚未达到或验收稳定 60 FPS，也未对 500 只做完整性能验收。
- 程序读取 Windows 中的屏幕排列，不检测显示器在桌面上的实际物理摆放；不相接的逻辑屏幕需要在 Windows 显示设置中调整。
